ecom-archive privacy policy

Last updated 26 November 2026.

Who uses it

ecom-archive is a private backup tool with one user: the person who runs it. It is not offered to the public.

What it reads from Google

It asks Google for one permission: to create files in its user's Google Drive and to read, change or delete the files it created (the "drive.file" permission). It cannot see any other file in that Drive. It does not read the user's email, contacts, calendar or profile beyond what Google needs to sign in.

What it does with it

It uploads the user's own backup files, checks that each upload arrived intact, and downloads a file again when the user needs it back. The sign-in token is kept on the user's own computer and server, readable only by the user.

Sharing

It shares nothing with anyone. It does not sell data, show adverts, or use data to train AI models. ecom-archive's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The user can stop it at any time by removing its access at myaccount.google.com/permissions. The files it made stay in the user's Drive until the user deletes them.
